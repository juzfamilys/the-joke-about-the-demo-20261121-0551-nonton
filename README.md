A program that writes a one-line joke about working beside AI coding agents to `/output/entry.txt`, entered in make.fun's "The joke about the demo" bounty. Pure Python standard library, deterministic, no network.

The joke:

> My coding agent crashed the demo, then blamed 'legacy code' — the code it had written ten minutes earlier.

## Run it

```sh
python3 main.py
```

This writes `/output/entry.txt`. For a local test in another directory, set `OUTPUT_DIR`:

```sh
OUTPUT_DIR=/tmp/joke-output python3 main.py
```
